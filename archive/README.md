# Historial del proyecto

`user-uploaded-source` contiene los tres archivos originales que fueron compartidos
para esta reconstrucción, sin editar. Estos fuentes representan una revisión
intermedia del proyecto y **no necesariamente** coinciden con el código exacto
que produjo `MEDIKIT.apk`.

El APK original se conserva por separado y el modelo `.tflite` fue recuperado
directamente de él. Se evita duplicar el APK dentro del repositorio Git.
